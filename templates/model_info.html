Academic Viva Voce & Project Demonstration Checklist

Traditional vehicle workshops rely on reactive maintenance (repairing vehicles after failure occurs) and paper/spreadsheet records, resulting in unexpected customer breakdowns and inefficient parts inventory. This web solution centralizes fleet records, calculates maintenance intervals in real time, and uses supervised machine learning to classify breakdown risk proactively before failures occur on the road.

The database schema follows 3rd Normal Form (3NF) to eliminate data redundancy:
  • users (user_id PK): Manages role-based accounts (Admin, Advisor, Customer) with hashed passwords.
  • customers (customer_id PK): Master table storing customer contact details.
  • vehicles (vehicle_id PK, customer_id FK): Tracks vehicle specifications linked to its owner with a UNIQUE registration number.
  • services (service_id PK, vehicle_id FK): Transaction table recording service date, mileage, labour costs, and status.
  • parts (part_id PK, service_id FK): Child table tracking individual parts replaced per service ticket.
  • predictions (prediction_id PK, vehicle_id FK): Audit table storing ML inference outputs (risk scores, failure flags, timestamps).

The architecture separates concerns into a layered model:
  • Presentation: Jinja2 templates render dynamic HTML enriched with Bootstrap 5 and Chart.js for data visualizations.
  • Routing & Security: Flask routes handle HTTP GET/POST verbs, validate input, manage user sessions, and apply @login_required and @role_required decorators.
  • Business & Service Layer: Dedicated service modules (services/) handle SQL queries using parameterized statements to prevent SQL injection.
  • Machine Learning Layer: Trained Scikit-learn pipelines (preprocessor + model) are serialized via joblib and loaded into memory for real-time inference.

We compared Logistic Regression and Random Forest Classifier:
  • Logistic Regression: Provides calibrated probabilistic outputs (0.0 to 1.0) and high interpretability for linear trends in mileage and service delays.
  • Random Forest: An ensemble of decision trees capturing non-linear interactions (e.g. older diesel vehicles with high mileage having disproportionately higher alternator/clutch failure rates).
  • The model with the superior F1-Score and ROC-AUC is automatically selected to prevent biased classifications.

  • Limitations: Currently relies on periodic workshop visits for odometer updates rather than live real-time telemetry.
  • Ethical Considerations: Customer privacy and vehicle usage data protection; preventing arbitrary price inflation based on algorithmic risk scores.
  • Future Scope: Integration with OBD-II IoT dongles (CAN-bus data) for continuous fault code (DTC) streaming, deep learning recurrent networks (LSTM) for remaining useful life (RUL) estimation, and SMS/WhatsApp automated service reminder integrations.
